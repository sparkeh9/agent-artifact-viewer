# Agent Artifact Viewer

A powerful, cross-platform viewer for agent-generated artifacts, built with **Tauri**, **React**, and **Rust**.

This application is designed to render and interact with complex markdown documents, code artifacts, and file structures generated by AI agents. It provides a rich, IDE-like experience for reviewing and navigating agent outputs.

## Features

-   **Markdown Rendering**: Full GitHub-flavored Markdown support, including tables, lists, and task lists.
-   **Syntax Highlighting**: robust code block highlighting for a wide range of languages using `highlight.js`.
-   **File Preview Tooltip**: Hover over file links to see a floating preview of the file content with syntax highlighting.
    -   **Interactive**: Move your mouse into the tooltip to scroll and read more.
    -   **Smart Positioning**: Automatically adjusts position to stay on screen.
-   **File Viewer Modal**: Click file links (in browser mode) to open a full modal viewer with syntax highlighting and copy functionality.
-   **Native Integration (Tauri)**:
    -   **Open in Default Editor**: Clicking file links opens them directly in your system's default editor (e.g., VS Code).
    -   **Secure File Access**: Reads local files securely via Rust backend.
-   **Mermaid Diagrams**: Renders Mermaid diagrams directly within markdown.
-   **Alerts & Callouts**: Supports GitHub-style alerts (Note, Tip, Important, Warning, Caution).

## Tech Stack

-   **Frontend**: React, TypeScript, Tailwind CSS
-   **Backend**: Rust (Tauri)
-   **Build Tool**: Vite

## Getting Started

### Prerequisites

-   Node.js (v16+)
-   Rust (stable)
-   Tauri CLI (`cargo install tauri-cli`)

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/sparkeh9/agent-artifact-viewer.git
    cd agent-artifact-viewer
    ```

2.  Install dependencies:
    ```bash
    npm install
    ```

### Running Locally

To start the development server with the Tauri backend:

```bash
npm run tauri dev
```

This will launch the application in a native window.

### Building for Production

To build the application for your operating system:

```bash
npm run tauri build
```

## Usage

The viewer is designed to be embedded or used as a standalone tool. It accepts markdown content and renders it with all the interactive features described above.

-   **Hover** over file links (`[file.ts](path/to/file.ts)`) to preview contents.
-   **Click** file links to open them in your editor (Desktop) or view in a modal (Web).
